# Theft Talk

Slash commands for the Theft Talk (@thefttalk) GTA 6 YouTube Shorts channel. Each command starts a full request in the chat, so a brand-new chat can make, schedule and check Shorts without re-explaining the channel.

- `/tt-short [streamer, Twitch clip link or idea]` - find, cut (title banner + punch-in) and schedule one clip Short
- `/tt-today` - fill the next 24 hours of slots (19:30, 21:30, 23:30, 05:30 IST)
- `/tt-upload [MP4 link] [IST time] [streamer + clip link]` - schedule a finished Short (private + publish time)
- `/tt-stats [trends]` - channel stats, winners and what's trending
- `/tt-reschedule [link or title] [new time | cancel | new text]` - move, cancel or re-word a Short
- `/tt-guide [side mission]` - Hindi side-mission guide Short

Works best with the theft-talk-studio skill and the Zapier skills theft-talk-upload-short, theft-talk-channel-stats and theft-talk-reschedule, with Zapier (YouTube) connected and the Mac linked for scouting and rendering.
